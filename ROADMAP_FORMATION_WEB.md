# Roadmap de développement — parcours d’apprentissage MIDEESSI Learn

- [ ] Vérifier la structure actuelle de la formation web dans les fichiers de données et de page détail
- [ ] Valider le parcours pédagogique avec les blocs : Fondamentaux, HTML, CSS, JavaScript, Vibecoding, Optimisation, Hébergement, SEO
- [ ] Confirmer la règle : 1 bloc = 1 cours + 1 quiz + 1 livrable

## 1. Base de données / contenus

- [ ] Ajouter les blocs pédagogiques dans la formation web
- [ ] Définir les objectifs de chaque bloc
- [ ] Définir le type de livrable pour chaque bloc
- [ ] Définir la durée estimée de chaque bloc
- [ ] Vérifier les niveaux et les prérequis

## 2. Interface formation

- [ ] Afficher le détail de la formation sur la page de détail
- [ ] Ajouter la section “Parcours d’apprentissage”
- [ ] Afficher les blocs dans l’ordre
- [ ] Afficher le statut de chaque bloc (À faire / En cours / Validé)
- [ ] Ajouter le bouton “Commencer le parcours”

## 3. Parcours bloc par bloc

- [ ] Créer la page bloc pour les fondements du web
- [ ] Créer la page bloc HTML
- [ ] Créer la page bloc CSS de base
- [ ] Créer la page bloc CSS layout & responsive
- [ ] Créer la page bloc JavaScript de base
- [ ] Créer la page bloc Vibecoding

- [ ] Créer la page bloc SEO

## 4. Quiz et notation

- [ ] Définir la règle de notation sur 100 par bloc
- [ ] Créer le moteur de quiz commun
- [ ] Ajouter 20 questions pour le bloc HTML
- [ ] Ajouter 20 questions pour les autres blocs
- [ ] Calculer immédiatement la note sur 100
- [ ] Afficher le message de niveau (Excellent / Très bien / Acceptable / À renforcer)

## 5. Livrables

- [ ] Définir les livrables de chaque bloc
- [ ] Prévoir les types de soumission : texte, lien, PDF, screenshot
- [ ] Créer le formulaire de soumission
- [ ] Ne pas bloquer la progression si le livrable n’est pas encore corrigé
- [ ] Enregistrer l’état de soumission

## 6. Anti-triche et sécurité simple

- [ ] Détecter la sortie de l’onglet
- [ ] Détecter le changement de focus
- [ ] Afficher un message d’avertissement
- [ ] Marquer la tentative comme suspecte
- [ ] Préparer la logique d’analyse côté admin

## 7. Progression utilisateur

- [ ] Suivre les blocs validés
- [ ] Suivre les blocs en cours
- [ ] Afficher la progression globale
- [ ] Autoriser la suite même sans correction humaine
- [ ] Sauvegarder la progression dans la base ou en local

## 8. Admin / gestion

- [ ] Créer la vue admin des contenus pédagogiques
- [ ] Ajouter les blocs dans le back-office
- [ ] Modifier les questions de quiz
- [ ] Voir les scores des élèves
- [ ] Voir les livrables soumis
- [ ] Corriger les livrables sans bloquer le parcours

## 9. Vérification et test

- [ ] Tester le parcours sur mobile
- [ ] Tester le parcours sur PC
- [ ] Vérifier le score automatique
- [ ] Vérifier la progression dès la fin du quiz
- [ ] Vérifier la cohérence graphique du parcours
- [ ] Vérifier que les CTA fonctionnent

## 10. Livraison MVP

- [ ] 1 formation : Développement Web
- [ ] 3 blocs complets minimum
- [ ] 1 quiz 20 questions par bloc
- [ ] Score immédiat sur 100
- [ ] Progression visible
- [ ] Livrable pratique
- [ ] Responsive mobile
- [ ] Validation fonctionnelle
